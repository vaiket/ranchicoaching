# Ranchi Coaching Landing Page

Production-ready Next.js landing page for Vaiket IT, focused on digital growth services for coaching institutes in Ranchi.

## Tech Stack

- Next.js 14 App Router
- TypeScript
- Tailwind CSS v3
- Framer Motion
- Recharts
- React CountUp
- React Intersection Observer

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build

```bash
npm run lint
npm run build
```
